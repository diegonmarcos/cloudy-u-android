# Sacred Geometry

A sibling project of `3.Projects/3.0.Chronos/` in this repository, shown in Cloud Wiki under Projects > Sacred Geometry (#1857).

- `index.html` is the Harmonic Lattice and Geometry 3D Explorer, an interactive Three.js page.
- `topics.md` is the curriculum map, from ratios and harmonics through 2D patterns, polyhedra and higher dimensions, growth and fractals, and nature, up to architecture and critical context.
