# #1666 Every location-class API call site in the SuperApp and every lib it links, with its OWNER. Read by
# test-location-use-scoped.sh: a call site missing here (or a count that grew) fails the build.
#
# Format:  path | api | count | trigger | owner and release
#   api      the scanner's class (location_use_scan.py APIS): fix, gnss, wifi-scan, wifi-info, ble-scan, cell, service-state,
#            hotspot, wifi-p2p, fgs-location
#   trigger  screen      runs only while its own screen is on screen (the user opened it); released when it leaves
#            button      runs only from a button the user pressed on an open screen; released by its Stop / on leave
#            weather     the Weather card's one coarse fix per 4 h (#1654), never a subscription
#            legacy-sdk  a branch only below the API level where Android has the location indicator (31), or where the
#                        location-free API does not exist (29); the modern branch beside it makes no location-class call
#   Nothing else is allowed: no timer, no service, no strip / widget refresh, no app start.
#
