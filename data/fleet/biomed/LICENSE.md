# Hardtech-BioMed served data: licences and attribution

Everything in this directory is read by Hardtech-BioMed at run time (never baked into the APK). `assets.json` is the register of every file here
(licence, source, author, sha256); `ad_Hardtech-BioMed/test/test-assets-licensed.sh` holds the directory to it.

| File | Licence | Source |
|---|---|---|
| `body.glb`, `brain.glb` | CC BY-SA 2.1 Japan (SPDX `CC-BY-SA-2.1-JP`) | BodyParts3D 4.0, derived by `ad_Hardtech-BioMed/tools/build_models.py` |
| `dna.glb` | CC0 1.0 (SPDX `CC0-1.0`) | generated by `ad_Hardtech-BioMed/tools/build_models.py`, no third-party input |
| `content.json` | CC0 1.0 | original educational text, written for this app (`tools/build_content.py`) |

## BodyParts3D (CC BY-SA 2.1 Japan)

BodyParts3D, (c) The Database Center for Life Science (DBCLS), licensed under CC Attribution-Share Alike 2.1 Japan
(https://creativecommons.org/licenses/by-sa/2.1/jp/ ; project page https://lifesciencedb.jp/bp3d/ ; data
https://dbarchive.biosciencedbc.jp/data/bodyparts3d/LATEST/).

`body.glb` and `brain.glb` are DERIVED from BodyParts3D 4.0 (`isa_BP3D_4.0_obj_99.zip`): the original meshes were simplified (vertex-clustering
decimation), moved to a metre / y-up coordinate system, merged into named groups and written as glTF binary. They are therefore adaptations and are shared
under the same licence, CC BY-SA 2.1 Japan, as the licence requires. Attribution is shown in the app under every 3D view (the `credit` and `licence` of each
model in `content.json`). The Hardtech-BioMed program code is a separate work and is not covered by this licence.
